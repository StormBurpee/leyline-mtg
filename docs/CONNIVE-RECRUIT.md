# Connive and recruit continuations

Rules profile: [Comprehensive Rules, effective 2026-09-25](https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt), particularly 701.50 (connive), 701.70 (recruit), 118.3/118.12 (optional costs), 400.7 (zone incarnations), and 608.2h (last known information).

- `connive` binds one source, event source, or targeted creature. Its current or last controller draws, then privately chooses a discard. An actually discarded nonland card puts a +1/+1 counter only on the same battlefield incarnation. A departed nontargeted creature still connives; an illegal target does not. A failed draw does not skip the discard. Draw triggers wait until the enclosing resolution finishes.
- Simultaneous multi-permanent connive is deliberately rejected: grouped connive selectors must have maximum one. APNAP controller ordering and each controller's choice of next permanent are not implemented. Serial instructions remain serial.
- `discardThen` discards a bounded count (1–16), snapshots the discarded cards' characteristics, and executes `then` **once if at least one discarded card matches `where`**. Omitted `where` matches any discarded card. This is an in-resolution continuation, not a reflexive stack trigger. No cards discarded means no continuation. Mandatory discards do as much as possible; optional payments require the full count and can be declined.
- Recruit uses draw one, then `discardThen` with a nonland filter and creation of a 1/1 white Human Soldier token. The token is created even if the ability's source has left.
- Recursive dependency checks preserve target-controller snapshots through continuations and reject unsupported linked-exile/temporary-mana combinations even when nested. Bot previews use the post-payment hand for draw bonuses, consider mandatory nested continuations, and leave optional inner payments as separate decisions. Filtered mandatory continuations are treated conservatively as possible; this is bounded policy safety, not universal tactical foresight.
- Grouped child decisions retain explicit continuation frames, preserving subsequent target groups and the original parent binding. No priority window opens between instructions. Last-known source updates visit suspended parent frames too.

The source set has 19 complete cards (18 new admissions and one Abandon Attachments migration against v58), including Formidable Speaker’s optional discard-linked creature search. Its focused test loads only those source definitions into a custom registry, so it does not need or modify generated catalogs. Other connive/recruit cards remain unsupported when they need additional mechanics, such as simultaneous choice ordering, connive replacement effects, once-per-turn optional performance gates, mayhem, or boast.
