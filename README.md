# Leyline

A JavaScript Magic: The Gathering rules engine and modern playable client, under active initial development.

The engine runs in Node.js and the browser without a Java backend. This first implementation targets a documented card and rules subset, not complete Forge compatibility. Executable card support, regression tests and limitations will be committed alongside the implementation.
